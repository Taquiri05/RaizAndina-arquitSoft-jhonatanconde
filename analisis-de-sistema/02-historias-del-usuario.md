# Historias de usuario

Formato: Como [actor], quiero [acción], para [beneficio].

| ID | Historia de usuario |
|---|---|
| HU01 | Como cliente, quiero registrarme con mis datos, para guardar mi historial, mis favoritos y mis puntos. |
| HU02 | Como usuario del sistema, quiero iniciar sesión con correo y contraseña, para acceder a las funciones de mi rol. |
| HU03 | Como cliente sin cuenta, quiero comprar como invitado, para hacer un pedido rápido sin registrarme. |
| HU04 | Como súper administrador, quiero crear, desactivar y asignar sede a las cuentas de administrador y cocina, para controlar quién opera cada sede. |
| HU05 | Como cliente, quiero elegir la sede antes de ver la carta, para pedir de la sucursal que me corresponde. |
| HU06 | Como cliente, quiero ver la carta por categorías con foto, precio y disponibilidad, para decidir qué pedir. |
| HU07 | Como administrador de sede, quiero crear, editar y marcar como agotado un producto de mi sede, para mantener la carta al día. |
| HU08 | Como cliente registrado, quiero marcar favoritos y calificar los platos que compré, para guardar mis preferencias. |
| HU09 | Como cliente, quiero armar mi carrito y elegir delivery o recojo, para preparar y confirmar mi pedido. |
| HU10 | Como cliente, quiero ver el estado de mi pedido en tiempo real, para saber cuándo estará listo. |
| HU11 | Como administrador de sede, quiero ver y filtrar los pedidos de mi sede, para controlar la operación diaria. |
| HU12 | Como cliente, quiero pagar con Yape, Plin, tarjeta o PagoEfectivo, para completar mi compra sin usar efectivo. |
| HU13 | Como administrador de sede, quiero que solo lleguen a cocina los pedidos con pago confirmado, para no preparar comida que no se cobró. |
| HU14 | Como personal de cocina, quiero ver los pedidos pagados en columnas por estado, para organizar la preparación sin papel. |
| HU15 | Como personal de cocina, quiero avanzar el estado de un pedido con un solo toque, para informar el avance de la preparación. |
| HU16 | Como usuario del sistema, quiero recibir solo las notificaciones de mi sede o de mis propios pedidos, para no ver información ajena. |
| HU17 | Como cliente registrado, quiero ver la disponibilidad y reservar una mesa, para asegurar mi lugar. |
| HU18 | Como administrador de sede, quiero ver las reservas del día y marcar llegadas, para atender bien el salón. |
| HU19 | Como cliente registrado, quiero acumular puntos y ver mi nivel, para obtener beneficios en mis próximas compras. |
| HU20 | Como administrador de sede, quiero que el stock se descuente automáticamente al venderse un plato, para no registrar cada venta a mano. |
| HU21 | Como súper administrador, quiero un dashboard con reportes consolidados de las 3 sedes, para entender cómo va el negocio. |
